Netflix Top 10 Analysis for Ghana and Nigeria
This notebook analyzes Netflix’s most popular shows in Ghana and Nigeria using publicly available data.
It demonstrates how to use Python and SQL to:

Load and explore Netflix Top 10 data.
Build and evaluate a simple linear regression model for price prediction (example code).
Query a database to identify the most watched shows in Ghana and Nigeria, based on cumulative weeks in the top 10.
How to Use
Open the notebook in DataLab or any Jupyter-compatible environment.
Run the cells in order to reproduce the analysis and visualizations.
Modify the SQL queries to explore other countries or metrics as needed.
Requirements
Python 3.x
pandas, numpy, scikit-learn, matplotlib
Access to the provided Netflix Top 10 database
Output
A table of the top shows in Nigeria (and Ghana, if available), ranked by weeks in the top 10.
Example code for linear regression modeling and visualization.
